One implementation lane (Sonnet 5.5 High). This is source and Linux checks only: no native actual, no Windows build, no review, no acceptance.

**What moved.** A building's link used to make the campaign compute its city's box (`ct_msgs.c update_city_bounding_box`: the scene bounds without lines, the heading's rotation of the two corners, the offset from the city, the union with the held box, which never shrinks). The shipping campaign now asks the host once per link (ENTITY_SCAN phase 15, CITY_EXPAND: the city's sector key and the building's key, nothing else) and applies the checked answer to its mirror. The reference host joins the pair to its roster, reads the city's own state and the building's fixed state it already holds (both stated before the link: `en_list.c` reports the child, then notifies LINK_CHILD), takes the bounds from its own model store, builds the box with the original's arithmetic (`model_step.c`, the existing caller-environment guard) and holds it in the city's record in one step. The original body is compiled only into the original-fixture build, byte-identical (`ct_msgs.c`: 50 insertions, 0 deletions). The host refuses by name, never a miss: a pair that does not join, a state it holds none of or withdrew, a scene it has no bounds for, a word that is not finite.

**Not moved (explicit next production).** `fx_int.c` collision-fixed/align/type predicates, then sector height/hints, UPDATED/shared terrain, raw tree/FOREST/CLOUD RNG, needed hierarchy/devices/DCS mapping, natural moving, and every delivery gate. All ten D3 requirements stay mandatory.

Over nine headings they leave the x87 control word and the MXCSR control and mask bits untouched and raise only the sticky inexact flag; nothing reads a flag and the engine entry restores the caller. The host kernel equals the control bit for bit over 1440 cases and returns the caller's complete state. The Windows toolchain is Root's native comparison.
