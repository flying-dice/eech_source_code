**When the M4 regression pack differs.**
- A red pack produces a proposal, not a new baseline. Baselines are never re-recorded in place, and a failing check is never made to pass.
- You run `baseline-governance.py propose`, which creates a change record under `regression/changes/`.
- You classify each delta, with evidence, as `regression` (rejected), `approved-defect-correction`, `intentional-semantic-change`, or `expected-input-world-variation`.
- The PR goes to review. Only fd-starscream-bot's approval of the commit holding that record counts.
- After approval, `adopt` verifies the review on GitHub and adds the new baseline version. The old version is kept.
